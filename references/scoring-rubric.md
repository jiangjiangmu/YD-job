# YD-job 打分契约（Scoring Rubric）v1

> 本契约与 `scripts/analyzer_engine.py` 的实现一一对应。修改打分逻辑时必须同步本文件；本文件是验收口径，测试按它断言。

## 1. 满分构成（总分 100）

| 维度 | 满分 | 说明 |
|---|---|---|
| 技能匹配 | 40 | 岗位技能标签命中 `profile.skills` 的比例 |
| 薪资匹配 | 25 | 岗位薪资区间与期望薪资的重合度 |
| 经验匹配 | 15 | 岗位经验要求与 `experience_years` 的契合度 |
| 学历匹配 | 10 | 岗位学历要求 ≤ 自身学历等级即可得满分 |
| 区域偏好 | 10 | `preferred_districts` 命中加分 |

**排除词罚分**：`job_name` 命中 `profile.excluded_keywords` 任意一项，**每项 -20 分**（可叠加），并写入备注。

## 2. 薪资解析规则（salary_score）

- 支持格式：`8K-12K` / `8-12K` / `12K以上` / `6-8K·14薪`（忽略 · 后缀）
- 输出 `(lo_k, hi_k, kind)`；`kind="k"` 为有效区间
- 无法解析（含"面议"）→ `kind != "k"` → 薪资维度不计分，备注"薪资面议/未标注"
- 期望薪资区间下限 ≥ 岗位下限视为达标；上限越界按比例折算

## 3. 经验匹配规则（experience_score）

- `经验不限` → 0.8 × 权重（15 分拿 12）
- 岗位区间完全覆盖自身年限 → 满分
- 自身年限超出要求上限 → `max(0.6, 上限/年限) × 权重`
- 年限不足下限 → 按比例扣减

## 4. 学历分级与匹配（degree_score）

学历等级（写死，不得增删乱序）：
`博士=5 硕士=4 本科=3 大专=2 中专=1 中技=1 高中=1 学历不限=0 初中=0`

- `岗位等级 ≤ 自身等级` → 学历维度满分
- `岗位等级 > 自身等级`（如本科岗投大专）→ **学历硬门槛阻断**：学历维度 0 分，且触发投递建议降档（见 §6）

## 5. 区域偏好（district_score）

- `district` 命中 `preferred_districts` → 满分
- 未命中但偏好区非空 → 0 分（备注"不在偏好区"）
- 岗位区域为空 → 不扣分

## 6. 投递建议档位（唯一口径，写死）

| 总得分 | 档位 | 颜色 |
|---|---|---|
| ≥ 70 | ⭐必投 | `C6EFCE` 绿 |
| ≥ 65 | 去 | `E2EFDA` 浅绿 |
| ≥ 58 | 可去 | `FFEB9C` 黄 |
| ≥ 48 | 缓 | `FCD5B4` 橙 |
| < 48 | 不去 | `FFC7CE` 红 |

**降档规则**：学历硬门槛阻断时，档位**降一档**（`b += 1`，且不超过「不去」）。如 ⭐必投(≥70 但本科门槛) → 去。

## 7. 输出契约

- 每行必须带：`综合得分`、`要不要去`（档位）、`匹配分析(为什么)`（✓ 达标项 / ⚠ 风险项）、五维分项
- 兼职/实习（`exclude_part_time: true`）不参与打分，归入"兼职实习(未打分)"附表
- 报告固定写入 `data/岗位分析报告.xlsx`，覆盖更新，禁止堆积时间戳版本
